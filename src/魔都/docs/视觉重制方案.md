# 魔都 · 视觉重制方案（v2）

> 依据：官方素材取色（`official-key-visual.jpg` / `official-logo.png`）+ 幻璃镜视觉体系 + galgame-frontend 技能规范。
> 目标：开场与游戏内**统一美学**，黑/紫/粉/白分区混合，成体系的材质与层级。

---

## 一、色源实证（从官方素材实际采样）

**官方 LOGO 内容平均色**：`#B5426C`（玫红/洋红）
**官方主视觉配色分布**（1400×1982 采样）：

| 占比 | 色值 | 定位 |
|---|---|---|
| 20.9% | `#181818` | 近黑主底 |
| 16.5% | `#787878` / `#A87878` | 中性灰白 |
| 9.4% | `#FF4848` | **主强调（亮红粉）** |
| 12.7% | `#FF7878` / `#FF4878` | 副强调（粉红） |
| 10.4% | `#481818` | 暗红棕阴影 |
| 5.8% | `#784878` | 紫红过渡 |
| 4.6% | `#481848` | **深紫底** |

→ 结论：官方美学 = **黑底 + 粉红强调 + 紫调过渡 + 高光白**。四族色板由此展开。

## 二、设计令牌（四族色板）

### 1. `ink` — 黑族（底材）
近黑到纯黑，作舞台底、面板底、文字底。

### 2. `rose` — 粉族（主强调）
暖粉红，作主角强调、对话框边线、激活态。

### 3. `orchid` — 紫族（氛围/过渡）
紫红到深紫，作背景氛围光、次级强调、夜色。

### 4. `paper` — 白族（文字/高光）
纸白到暖灰，作正文、标签、高光描边。

---

## 三、分区混色策略（回应"黑、紫、粉、白混合不同部分"）

不是单一色调，而是**按区域职能分配色相**：

| 区域 | 主色相 | 说明 |
|---|---|---|
| 深空背景 / 舞台底 | **黑 + 紫** | 紫调辉光在四角渗入，中央留黑 |
| 角色立绘位 / 主视觉 | **紫 + 粉** | 全息剪影用紫粉渐变，背光用粉 |
| 对话框 | **黑 + 粉边 + 白字** | 琉璃黑底、粉金细边、纸白正文 |
| HUD 状态条 | **黑 + 白 + 粉点** | 冷白文字，粉/紫状态指示 |
| 弹窗 | **深紫底 + 粉边 + 白字** | 紫黑面板，粉强调，白正文 |
| 按钮 | **黑底 + 粉/紫描边** | 悬停粉辉，激活紫金 |
| 氛围粒子 | **粉 + 紫 + 白** | 三色微粒混合 |

## 四、层级令牌（z-index 统一）

仿幻璃镜"统一浮层层级令牌"，禁止任意裸数字：

```
舞台底        z-0 / z-10
氛围粒子      z-[15]
角色层        z-20
HUD           z-30
对话框        z-40
弹窗          z-50
通知          z-[60]
开场覆盖      z-[100]
```

## 五、材质与动效清单

**材质类**（`@layer utilities`）
- `.surface-vn` — 视觉小说式透明顶缘渐入深墨 + 背模糊
- `.edge-hairline` — 顶部粉金细双线 + 菱珠
- `.panel-glass` — 紫黑玻璃面板（弹窗/卡片通用）
- `.nameplate` — 名牌（左端色釉竖条 + 右端菱收尾）
- `.text-sheen` — 标题粉金流光字
- `.tex-grain` — 细腻颗粒纹理
- `.vignette` — 舞台暗角（视线聚拢）
- 色相辉光 `.glow-rose` / `.glow-orchid`

**动效 keyframes**
- `mato-orbit` — 环形轨道旋转（背景装饰环）
- `mato-breathe` — 呼吸明灭（辉光）
- `mato-mote` — 微粒上浮（氛围粒子，三色）
- `mato-sheen` — 流光扫过（标题）
- `mato-scan` — 扫描线（战术感残留）
- `mato-glitch` — 故障抖动（战斗/告警）
- 全部在 `prefers-reduced-motion: reduce` 下关停。

## 六、素材使用

| 素材 | 尺寸 | 用途 |
|---|---|---|
| `official-logo.png` | 1194×630，**带透明** | 开场主标题 LOGO、游戏内 HUD 角落小标 |
| `official-key-visual.jpg` | 1400×1982 竖版 | 开场主视觉底图（含遮罩处理）、游戏内角色位 |

处理原则：**内联为 data URI**（保持单文件交付），并提供 `mask`/`opacity` 让它与深色舞台融合，而非硬贴。

## 七、施工顺序

1. `index.css` — 色板 + 令牌 + 材质 + 动效（地基）
2. 开场 `SystemBoot` / `BootSequence`（含 LOGO + 主视觉）
3. 主舞台（背景层 / 角色层 / 前景层）
4. `HUD` + `DialogueBox`
5. 四弹窗 + 通知 + `TacticalButton`
6. 氛围层组件（新增）
7. `CombatTerminal` 外观对齐
8. 构建 + 无头验收 + 截图
