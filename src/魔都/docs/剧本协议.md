# 魔都 · 剧本输出协议（v1）

> 这份文档是**合同**。左半边是给 AI 的规矩（写进世界书「格式」条目），
> 右半边是前端 `src/scriptParser.ts` 的解析实现。**两端必须逐字对齐**。
> 改协议 = 改两个地方，改一个必炸。

---

## 一、行格式总表

| 格式 | 类型 | 解析正则（`s` 标志） |
|---|---|---|
| `角色名[情绪]:"对话"` | dialog | `/^(.+?)\[(.+?)\]:"(.+)"$/s` |
| `<user>:"对话"` | dialog（玩家） | `/^<user>:"(.+)"$/s` |
| `角色名[情绪]:*内心独白*` | thought | `/^(.+?)\[(.+?)\]:\*(.+)\*$/s` |
| `<user>:*内心独白*` | thought（玩家） | `/^<user>:\*(.+)\*$/s` |
| 纯文本 | narrator（旁白） | 兜底 |

**只做行首整行匹配，绝不扫描自由文本。** 这是为了让旁白里的引号台词不被误认成对话：

```
他说"我陪你"——但声音是从耳机里传来的。     ← 旁白，正确
羽前京香[冷静]:"信号确认。"                  ← 对话，正确
```

---

## 二、行锚定铁律

1. **对话行整行只允许这一个表达式**，行首行尾不得有任何其他文字。
2. **引号、冒号、方括号一律英文半角**。全角 `："` 不匹配。
3. 情绪标签必须有，不能省。想表达"边动边说"就拆成旁白行 + 对话行。
4. 一行一句话。不要在一行里塞两段对话。

---

## 三、控制行

### `[scene:父地点/子地点/末级地点]`

- **行首、独占一行**，不产生可播行（玩家看不到）。
- 语义是「**从此生效直到下一个控制行**」——后续所有行继承这个场景。
- 支持任意层级，显示名取路径最后一段。

```
[scene:魔都/第七区/废弃车站/站台]
```

### 行首标签前缀（可选）

AI 有时会把人物标签和对话写在同一行，前端会归一化后再解析：

```
[队员:甲,状态=警戒][紧张]:"有动静。"     → 说话人 = 甲
```

---

## 四、选项

**三路并取**（AI 记不住只用一种格式，前端全兼容，按优先级）：

```xml
<options>
<option>原地待命，继续观测</option>
<option>沿铁轨向前推进</option>
</options>
```

```xml
<options>
> 原地待命，继续观测
> 沿铁轨向前推进
</options>
```

```xml
<choice>
1. 原地待命，继续观测
2. 沿铁轨向前推进
</choice>
```

选项块**必须放在正文之外**（`</content>` 之后）。前端会自动把它从正文滤净，
漏在 `<content>` 里会被当旁白念出来。

---

## 五、正文包裹

```
<content>
（这里才是剧本）
</content>
```

- 可播内容只来自 `<content>…</content>`，可以多个（思维链夹心时前端"首开到末闭"合并）。
- **没包 `<content>` 时降级为「剥思维链后全文视为剧本」**——AI 忘包标签不该让整楼播不出来。
- `<thinking>` / `<draft>` 等思维链标签内的内容一律不进剧本。
- `<UpdateVariable>` 变量块不进剧本（MVU 框架管落盘）。

---

## 六、AI 侧 COT 自检模板（写进世界书）

> 输出正文前，逐条自检：
> 1. 剧本是否全部包在 `<content>` 标签内？
> 2. 每句对话是否都是 `角色名[情绪]:"台词"`，引号冒号是否半角？
> 3. 是否有对话行在行首行尾夹了其他文字？（必须拆行）
> 4. 场景切换是否用了独立的 `[scene:…]` 行？
> 5. 选项块是否放在 `</content>` 之后，没有混进正文？

## 七、角色与情绪

**角色表**在 `src/data/cast.ts`，新增角色只改那里。

| 角色 | 别名 | 主题色 | 备注 |
|---|---|---|---|
| 羽前京香 | 京香 / 组长 / 羽前组长 | rose 粉 | 第七组组长 |
| 和仓优希 | 优希 / 和仓 | orchid 紫 | 玩家角色，不占立绘位 |
| 系统 | SYSTEM / 系统消息 | paper 白 | 系统播报，不占立绘位 |

**情绪**（`EMOTION_MAP`，中文名 → key）：
默认 / 冷静 / 微笑 / 严厉 / 愤怒 / 惊讶 / 担忧 / 疲惫 / 嘲讽 / 温柔 / 痛苦 / 决然

写错的情绪**不会丢行**，回落 `default`。写错角色名会落到无主题色的旁白样式，
所以宁可只用表内角色名。
